shortDescription: Plataforma de microservicios para digitalizar procesos académicos y administrativos en Fundación Kinal.
description: >-
  Kinal Reports es una plataforma web desarrollada bajo una arquitectura de microservicios
  para digitalizar y optimizar procesos académicos y administrativos dentro de Fundación
  Kinal. El sistema permite gestionar solicitudes de documentos, horarios, eventos,
  notificaciones, comunicación entre estudiantes y profesores, así como el seguimiento del
  estado de los docentes, reduciendo procesos manuales y mejorando la eficiencia institucional.

learned: >-
  Este proyecto me enseñó a diseñar funcionalidades pensando en usuarios con necesidades

  clave para mantener la integración entre los distintos microservicios sin afectar el
  funcionamiento del sistema.
features:
  - Sistema basado en microservicios
  - Autenticación y autorización mediante JWT
  - Gestión de usuarios con roles (Administrador, Profesor y Estudiante)
  - Solicitud y aprobación de documentos administrativos
  - Consulta de horarios por profesor, sección y salón
  - Gestión de eventos académicos
  - Sistema de notificaciones
  - Chat entre estudiantes y profesores
  - Consulta del estado y ubicación de docentes
  - Generación de reportes administrativos
  - Seguridad mediante validación de roles, rate limiting y protección de endpoints
